# Coron Tour Itinerary Planner

A web application for planning tours and managing itineraries for Coron, Palawan in the Philippines.

## Features

- View flight itinerary between Manila and Palawan
- Browse available tours in Coron with detailed information
- Select up to two tours for your visit
- View comprehensive pricing for both private tours and joiners rates
- Calculate total cost including airport transfers
- Mobile-responsive design

## How to Use

1. **View Your Itinerary**: Check your flight details between Manila and Palawan.
2. **Browse Tours**: Explore the various tours available in Coron, including:
   - Town Tour
   - Mt. Talapay & Town Tour
   - Tour A (Kayangan Lake, etc.)
   - Tour B (Barracuda Lake, etc.)
   - Super Ultimate Tour
   - Island Escapade
   - Reef & Wreck
   - Calauit Safari
   - Dugong Watching

3. **Select Tours**: Choose up to 2 tours for your visit by clicking the "Select Tour" button.
4. **Review Summary**: View your selected tours and total cost in the summary panel.
5. **Book**: Click the "Book Now" button to confirm your selection.

## Price Information

The website displays two pricing schemes:

1. **Private Tour Rates**: Pricing based on the number of participants (from 1 to 16+ people)
2. **Joiners Rate**: Per-person pricing for joining group tours

The airport transfer fee (₱500 for a two-way trip) is included by default but can be toggled.

## Development

This project uses:
- HTML5
- CSS3 with responsive design
- Vanilla JavaScript

To run the project locally, simply open `index.html` in your web browser.
