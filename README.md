# Philippines Trip Itinerary - May 2025

This repository contains a website for planning and viewing an itinerary for a trip to the Philippines in May 2025, focusing on Coron, Palawan.

## Website Structure

- **index.html** - Main page with trip overview and interactive calendar
- **tours.html** - Information about booked tours (Super Ultimate Tour and Reef & Wreck Tour)
- **food.html** - Food options during the trip with Google Maps links
- **flights.html** - Flight details (planning page)
- **accommodations.html** - Accommodation details (planning page)

## Project Features

- Interactive grid-based calendar with detailed dropdown information
- Color-coded days for different types of activities
- Complete tour information with pricing in PHP and USD
- Restaurant listings with Google Maps integration
- Responsive design for all screen sizes

## Setup Instructions

1. Clone this repository
2. Open `index.html` in your web browser to view the site
3. No build tools or server required - pure HTML, CSS, and JavaScript

## Development Notes

- Currency conversion rates used: 1 USD = approximately ₱56 PHP
- Color coding system:
  - Green: Arrival days
  - Red: Departure days  
  - Yellow: Travel days
  - Blue: Tour days
  - Dark blue: Special events
  - Light blue: Free days
